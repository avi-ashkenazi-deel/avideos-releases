Settings

        
      

      

        
Prompt interpreter

        
By default the brief is read by a built-in rule parser (formats, mood, emphasis, count, quoted copy, brand color names). Optionally, let Claude read the brief and turn it into the same constraint JSON. The key stays in this browser only and is sent straight to Anthropic.

        

        
        
Runs when the page is served locally or from your own host. Published copies block outbound requests, so the rule parser is used there.

        

        
Image generation

        
Image blocks on the canvas can ask a model for a picture that matches the frame's copy and palette. Pick a provider and paste its key; the key stays in this browser and is sent only to that provider.

        

          

          

          

        

        
Like the interpreter, this runs locally or from your own host only. Published copies block outbound requests.
